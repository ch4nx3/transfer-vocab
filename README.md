# 🎯 서·성·한 편입영어 10일 완성 계단식 보카 학습기 (2023-2025 최신기출 420제)

서강대학교, 성균관대학교, 한양대학교 최신 3개년(2023~2025) 편입영어 기출 어휘 420단어를 10일 동안 매일 42단어씩 학습하는 반응형 모바일 최적화 웹앱입니다.

## 🚀 온라인 실시간 학습 접속
👉 **https://ch4nx3.github.io/transfer-vocab/**

## ✨ 주요 기능
1. **퀴즈렛(Quizlet) 스타일 플래시카드**: 단어, 한국어 뜻 가림막/공개 토글, 기출 문맥 예문 및 형광펜 하이라이트, 동의어 칩, 원어민 발음 TTS.
2. **계단식 폭포수 누적 복습 (Spaced Repetition)**: 1일차 오답 단어가 2일차 테스트에 자동 이월되어 마스터할 때까지 지속 누적 테스트.
3. **오답 즉시 재시험 & 1:1 클리닉 리포트**: 스마트 채점 엔진, 오답노트 마크다운 클립보드 복사.
4. **모바일 최적화 (PWA)**: 홈 화면에 추가하여 오프라인에서도 네이티브 앱처럼 풀스크린 학습 지원.
