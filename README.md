## ✨ 1. 문장해석 & 기출문법 실전 트레이너 (NEW)
> **접속 URL**: https://ch4nx3.github.io/transfer-vocab/trainer.html (또는 [sentence.html](https://ch4nx3.github.io/transfer-vocab/sentence.html))

1. **📖 문장 해석 실전 모드 (10일 완성 데일리 10제)**:
   - **모바일 최적화 1~2문장**: 장지문에서 핵심 10대 통사 구조(도치, 분사, 관계사, 부정, 비교, 가주어/가목적어, 동격/삽입, 물주구문, 가정법, 복합논리) 100문장 엄선.
   - **능동적 인출(Active Recall)**: 화면을 보며 내 손으로 직접 한국어 번역을 타이핑.
   - **AI 모범 번역 즉시 대조**: 완료 시 공식 AI 번역, 직독직해 구문 해체, 핵심 어휘 사전, 출제 함정 구문 팁 자동 리빌.
   - **3단계 메타인지 자가평가**:  /  /  체크 및 오답노트 마크다운 복사.
2. **✏️ 기출 문법 전용 모드 (서·성·한 35제 문제은행)**:
   - **문법 문제 완전 분리**: 서강대 19제, 성균관대 15제, 한양대 1제 (총 35문항) 전용 모드.
   - **지문 내 오류 실시간 하이라이트**: 선지 클릭 즉시 지문 속 오답 어구에 형광펜 및  뱃지 표시.
   - **4단계 심층 클리닉**: 정답 이유, 킬러 출제 공식, 5개 선지별 함정 분석, 전 지문 전문 해석.
   - **영역별/대학별 필터**: 수일치, 준동사, 관계사, 도치, 품사/어형 등 취약 영역만 골라 풀기.

## 📚 2. 10일 완성 계단식 보카 학습기
> **접속 URL**: https://ch4nx3.github.io/transfer-vocab/

1. **퀴즈렛(Quizlet) 스타일 플래시카드**: 단어/뜻 가림막, 기출 문맥 예문 형광펜, 동의어 칩, 원어민 TTS.
2. **계단식 폭포수 누적 복습**: 1일차 오답이 2일차 테스트에 자동 이월되어 마스터할 때까지 지속 누적 테스트.
3. **스마트 채점 & 1:1 클리닉**: 유사도 기반 자동 채점, 오답노트 마크다운 클립보드 복사.
